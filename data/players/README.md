# Статистика игроков по каткам КВ

Файлы: `18-ih.json`, `17-44th.json`, …

Формат:

```json
{
  "total": [
    { "nick": "Keech", "res": 0, "nok": 0, "kills": 0, "deaths": 0, "dmg": 0 }
  ],
  "r1": [],
  "r2": []
}
```

Столбцы со скрина: Ресы=1, Ноки=3, Килы=4, Смерти=5, Боевой счёт=9 (в JSON — `dmg`).
Медаль за макс. боевого счёта: **MVP War-Score**.
  
В `2026-09.json` у катки: `"playersUrl": "data/players/18-ih.json"`.
